# SteamDB 覆盖率实测报告(2026-08-30)

## 方法

在浏览器隔离上下文(无扩展干扰)中逐页加载 SteamDB,提取全部可见文本节点
(含 placeholder 与 aria-label,过滤纯数字/含中文文本),与 v1.0.1 词库的
1359 个英文键做精确匹配,收集未命中文本。

覆盖页面:首页、/charts/、/graph/、/app/730/、/app/730/info/、/sales/、
/calendar/、/tech/。共收集未命中文本约 2500 条,人工甄别出真 UI 词条。

## 结果(v1.1.1 已收录 +136 条)

| 类别 | 处理 |
| --- | --- |
| 分页/计数动态文案(DataTables "Showing…entries"、"Displaying change N of M") | 新增 REGEX 正则规则段(16 条),引擎同步支持 |
| 筛选器/日历/折扣图例/浏览器插件提示/加载态等界面文案 | 静态词条约 110 条 |
| 无障碍特性与手柄特性列表(charts 侧栏) | 全量收录约 26 条 |
| 常见标签(charts 标签筛选) | 收录实测出现的部分 |
| 表格排序 aria-label("…: Activate to sort") | LABEL 段 10 条 |
| 游戏名/价格/日期/技术专有名词(tech 页) | **有意不翻**(数据与专有名词) |
| 被 `<a>` 拆碎的句子片段(FAQ、搜索提示) | **有意不翻**(碎片直译会产生破句,待引擎支持跨节点句段合并后再议) |

## 已知遗留缺口

1. **标签词库不全**:Steam 标签总量 400+,实测只覆盖出现频率高的一批
   (上游词库 + 本补充)。遇到漏翻标签属预期。
2. **跨节点句子**:"This app does not have … Steam Auto-Cloud … configured,"
   这类被链接打断的句子无法整句命中。
3. **未覆盖页面**:/badges/、/calculator/、/packages/、/search/ 深层结果页、
   登录后的个人页面(愿望单/追踪列表)。
4. **DataTable 列表头动态排序提示**已覆盖常见列,冷门列名可能遗漏。

日常发现漏翻:开启脚本菜单"输出未命中词",把控制台输出发给维护者补充。
